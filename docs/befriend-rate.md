# 戦闘後にともだちになる確率

## 概要

通常の戦闘後に敵妖怪1体がともだち候補として当選する確率は、基礎確率へ食べ物、スキル、
さすらい玉などの値を足して決まります。各効果は基礎確率への倍率ではなく、確率へ直接加える
「パーセントポイント」です。

```text
最終確率 = 基礎確率
         + 食べ物
         + モテモテ
         + モテない
         + さすらい玉
         + つつく
         + おさい銭
```

基礎確率を決める難度は、現在登録されている同種妖怪の数によって変わります。登録数が0〜5体の
ときに使う難度テーブルは妖怪ごとに個別設定されています。

難度が1〜8なら、基礎確率は `1 / 2^(難度 + 2)` です。

| 難度 | 基礎確率 |
| ---: | ---: |
| 1 | 12.5% |
| 2 | 6.25% |
| 3 | 3.125% |
| 4 | 1.5625% |
| 5 | 0.78125% |
| 6 | 0.390625% |
| 7 | 0.1953125% |
| 8 | 0.09765625% |

複数の敵が個別抽選に当選しても、実際にともだちになるのは1体です。当選者のうち、
まだ1体も登録していないときの基礎確率が最も低い妖怪が優先されます。同じ基礎確率の
妖怪が複数いる場合は、その中から等確率で1体が選ばれます。

## 難度テーブル

現在の登録数によって、その妖怪の種類の現在の難度が決まります。

例: ジミーの難度テーブル

| 登録数 | 難度 | 確率 |
| ---: | ---: | ---: |
| 0 | 2 | 6.25% |
| 1 | 4 | 1.5625% |
| 2 | 5 | 0.78125% |
| 3 | 5 | 0.78125% |
| 4 | 6 | 0.390625% |
| 5 | 7 | 0.1953125% |

例: ヒカリオロチの難度テーブル

| 登録数 | 難度 | 確率 |
| ---: | ---: | ---: |
| 0 | 7 | 0.1953125% |
| 1 | 8 | 0.09765625% |
| 2 | 8 | 0.09765625% |
| 3 | 8 | 0.09765625% |
| 4 | 8 | 0.09765625% |
| 5 | 8 | 0.09765625% |

同種妖怪がすでに6体登録されている場合は、通常の戦闘後抽選の対象になりません。

### 食べ物

食べ物の加算値は、妖怪の難度と食べ物ランクで変わります。

| 難度 | ランク1 | ランク2 | ランク3 | ランク4 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | +10% | +15% | +20% | +25% |
| 2 | +5% | +8% | +11% | +14% |
| 3 | +4% | +6% | +8% | +10% |
| 4 | +4% | +5% | +6% | +7% |
| 5 | +3% | +4% | +5% | +6% |
| 6 | +2% | +3% | +4% | +5% |
| 7 | +1% | +2% | +3% | +4% |
| 8 | +1% | +1% | +2% | +3% |

好物なら、この食べ物による加算値だけが1.5倍になります。苦手な食べ物なら0.4倍です。
基礎確率には掛かりません。

たとえば難度4の妖怪の登録数が0体の場合、基礎確率は `1 / 64 = 1.5625%` です。
ランク4の好物を与えると、食べ物の加算は `7% × 1.5 = 10.5%` なので、ほかの効果が
なければ合計は12.0625%です。

### モテモテ・モテない

モテモテとモテないの値は難度ごとに異なります。

| 難度 | モテモテ | モテない |
| ---: | ---: | ---: |
| 1 | +10% | -10% |
| 2 | +5% | -4.5% |
| 3 | +4% | -2% |
| 4 | +4% | -1% |
| 5 | +3% | -0.5% |
| 6 | +2% | -0.25% |
| 7 | +1% | -0.1% |
| 8 | +1% | -0.05% |

同じ種類のスキルを複数の味方が持っていても、その効果の加算は1回だけです。

### さすらい玉などの効果

これらは難度に関わらず、直接加算されます。

| 効果 | 確率への加算 |
| --- | ---: |
| 青いさすらい玉（ハート1個） | +10% |
| 金のさすらい玉（ハート3個） | +100% |
| ともだち確率が上がる「つつく」 | +10% |
| おさい銭の当たり効果 | +1% |

金のさすらい玉は100パーセントポイントを加えるため、通常の確率計算へ進んだ妖怪の
個別抽選は必ず当選します。ただし、同種を6体登録済みの妖怪や、特殊な戦闘ルールで
抽選対象外になっている妖怪には効きません。

## 内部処理

### 基礎確率の取得

基礎確率を決める値は、`data/res/character/chara_param_0.03a.cfg.bin` の
`CHARA_PARAM_INFO` にあります。CFGでは0始まりの値番号31、行の開始位置を `R` とした
ときの `R + 0x90`、ランタイムのキャラクターパラメータ構造体では `+0x20` の32ビット値です。

この値は妖怪ごとに異なり、4ビットずつ登録数0〜5体に対応する6個の難度に分かれています。
ジミーの内部IDは `y197000` です。`CHARA_PARAM_INFO` index 237、ファイルオフセット
`0xD5FC` にある難度テーブルの生値 `0x00765542` が、順に `2, 4, 5, 5, 6, 7` に
対応します。

ヒカリオロチの内部IDは `y221020` です。`CHARA_PARAM_INFO` index 295、ファイルオフセット
`0x10A8C` にある難度テーブルの生値 `0x00888887` が、順に `7, 8, 8, 8, 8, 8` に
対応します。
現在登録されている同種妖怪の数を `c` とすると、難度 `d` は次のように取り出されます。

```text
c >= 6:
    抽選対象外

c < 6:
    d = (friendDescriptor >> (4 * c)) & 0xF
```

同種妖怪の登録数を数える関数は `sub_4A5B28`、難度レコードの取得は `sub_64A550`、
4ビット値の取出しは `0x64A568`〜`0x64A570` です。難度が1〜8以外なら抽選対象外です。

### 加算値と食べ物倍率

難度ごとの値は、同じCFGの `CHARA_FRIEND_RATE_INFO` index 1185〜1192、
ファイルオフセット `0x2EEA4`〜`0x2F010` にあります。基礎確率の分母を除き、格納値の
100が1%に相当します。

敵1体の確率計算と抽選を行う関数は `sub_652040` です。食べ物処理は
`0x652184`〜`0x652238` にあります。

1. 食べ物IDからランク1〜4を取得します。
2. 現在の難度行から対応する加算値を読みます。
3. 好物カテゴリなら1.5倍、苦手カテゴリなら0.4倍します。
4. 小数点以下を切り捨て、最終的な加算値へ入れます。

好物倍率のバトル変数IDは `0xD854C36D`、苦手倍率は `0x0EEE0DA5` です。
食べ物ランクの取得は `0x6521AC`、好物倍率の適用は `0x6521E4`、苦手倍率の適用は
`0x652220` にあります。

その後、次の順で各効果を加算します。

| 要因 | 判定 | コードアドレス |
| --- | --- | ---: |
| モテモテ | 効果ID `0xD73492CD` | `0x652260`〜`0x652284` |
| モテない | 効果ID `0xB69495A4` | `0x652288`〜`0x6522A4` |
| さすらい玉 | 戦闘状態 `+0x5E18 == 5` | `0x6522A8`〜`0x6522E0` |
| つつく | 対象妖怪の専用フラグ | `0x6522E4`〜`0x6522F0` |
| おさい銭 | ビットフラグ `0x8B049510` | `0x6522F4`〜`0x652308` |

青いさすらい玉の格納値は1000、金は10000です。戦闘全体の状態から読み出すため、
抽選対象になった敵それぞれへ同じ値が加算されます。

### 乱数判定

基礎確率の分母を `N`、全加算値を `B` とすると、`0x652340`〜`0x652374` では次の
整数計算を行います。`B = 10000` が100%です。

```text
numerator   = 10000 + B * N
denominator = 10000 * N
r = randomInteger(0, denominator - 1)

当選 = numerator > r
```

したがって、通常時の個別抽選確率は厳密に `1 / N + B / 10000` です。分子が分母以上なら
必ず当選し、分子が0以下なら当選しません。乱数との比較は `0x65236C`、範囲指定乱数関数は
`sub_556318` です。

### 複数当選時の選択

候補収集と最終選択は `sub_54FF30` が行います。最大12枠に対する個別抽選は
`0x55027C`〜`0x55031C`、当選者の基礎確率を比較する処理は
`0x5502CC`〜`0x550310`、同順位から1体を選ぶ乱数は `0x550334` にあります。

優先順位の比較には、現在の登録数ではなく、同種をまだ1体も登録していない場合の難度を
使います。その基礎確率が最も低い当選者だけを残し、同率なら等確率で1体を選びます。
