# えんえんトンネルの汽車

## 概要

えんえんトンネルの汽車には、次の4種類の移動量が指定されています。予定の出口が
近いときには、実際の前進距離が短くなる場合があります。

| 行き先 | 指定移動距離 |
| --- | ---: |
| 前進 | 2,000m |
| 前進 | 1,000m |
| 後退 | 500m |
| 後退 | 1,000m |

序盤に現れる汽車は前進だけで、進むにつれて後退する種類も候補に加わります。
乗車を断れば、汽車による移動は起こりません。

**妖怪やNPCなどのイベントに出会う機会を優先するなら、汽車には乗らずに歩くのが堅実です。**
前進すると途中の区画を飛ばすため、その区間のイベントには出会えません。
後退すれば歩き直せますが、4種類すべてが候補になる距離では、前進する種類の重みの合計が
後退する種類より大きく、移動距離を含めても前進寄りです。

汽車で後退しても、予定されていた出口が手前に移ることはありません。出口まで歩く距離は
その分長くなります。前進した場合も、通常は予定の出口を変えません。移動先が予定の出口に
達するか越えると、設定上限の範囲で出口は移動先の次の50m区画まで延びます。上限に
達している場合は出口をそれ以上延ばせず、汽車の着地点が出口の手前へ補正されます。
固定距離の回も同様です。予定の出口位置は画面に表示されないため、乗車前にこの補正が
起こるかどうかは判断できません。

## 内部処理

### 4種類の候補と重み

汽車は`data/res/enen_tunnel/enen_tunnel_event.cfg.bin`のイベント項目63〜66にあります。
出現条件に使う区画番号と、マップスクリプトで指定する移動量は次のとおりです。
えんえんトンネルの1区画は50mです。

| イベント項目 | ファイル内オフセット | 候補になる区画番号 | 重み | マップコマンド | 指定移動量 |
| ---: | ---: | ---: | ---: | --- | ---: |
| 63 | `0x1610` | 5以上 | 0.02 | `RunCmd_Map257` | +40区画、2,000m |
| 64 | `0x164C` | 5以上 | 0.03 | `RunCmd_Map258` | +20区画、1,000m |
| 65 | `0x1688` | 10以上 | 0.02 | `RunCmd_Map259` | -10区画、500m |
| 66 | `0x16C4` | 20以上 | 0.01 | `RunCmd_Map260` | -20区画、1,000m |

区画番号20以上で4種類が同時に候補になるとき、前進の重みは`0.02 + 0.03 = 0.05`、
後退の重みは`0.02 + 0.01 = 0.03`です。直前の選択による候補の除外がない場合、
汽車イベント内での前進と後退の比率は5対3になります。同じ条件で指定移動量を
重み付けした平均は前方へ625mです。実際の移動は出口の上限による補正を受けます。

```text
(2,000m × 0.02 + 1,000m × 0.03 - 500m × 0.02 - 1,000m × 0.01)
÷ (0.02 + 0.03 + 0.02 + 0.01) = +625m
```

この数値は汽車の4種類が同時に候補になった場合の内訳です。区画のイベント選択では
ほかのイベントの条件と重みも確認し、直前に選ばれた候補を一時的に除外する処理もあるため、
表の重みは汽車との遭遇確率そのものではありません。候補の抽選は`code.bin`の
`sub_497114`（`0x497114`）で行います。

### 乗車後の移動と出口

マップスクリプト`data/res/map/t131d20/t131d20.pck`内の`RunCmd_Map257`〜
`RunCmd_Map260`は、乗車が選ばれたときだけ移動コマンドを呼びます。移動コマンドに渡す
符号付き区画数が、上の表の`+40`、`+20`、`-10`、`-20`です。

移動先の計算は`code.bin`の`sub_49787C`（`0x49787C`）、出口と移動先の補正は
`sub_497AE0`（`0x497AE0`）で行います。出口の予定区画は管理オブジェクトの`+0x17C`、
汽車の移動先は`+0x17E`に別々に保存されます。出口の予定区画は、元の値と
「移動先の次の区画」の大きい方を基準にし、設定上の下限・上限に収めて更新されます。
このため、後退しても予定の出口は短くなりません。前進で出口に達するか越える場合は、
設定上限の範囲で出口が延びます。上限を超える移動先を指定した場合、出口は上限区画で
止まり、移動先はその出口を越えない区画へ補正されます。固定距離の回は上下限が同じなので、
前進によって出口が延びることもありません。

移動の反映は`sub_4958BC`（`0x4958BC`）が担当します。前進では途中の区画を歩かず、
移動先付近のイベントを生成します。後退では移動先までの区画のイベント記録を消してから
移動先付近を生成し直すため、歩き直した区画で再びイベントの候補を引くことができます。
