# えんえんトンネルの距離

## 概要

えんえんトンネルでは、入るときに出口までの予定距離が決まります。出口側のイベントで
進行が記録されると、次回の設定が切り替わります。

| 挑戦回数 | 入場時の予定距離 | 出口位置の上限 |
| ---: | ---: | ---: |
| 1回目 | 794m（固定） | 794m |
| 2回目 | 1,050～2,049m | 2,000～2,049m |
| 3回目 | 1,050～3,049m | 3,000～3,049m |
| 4回目 | 4,949m（固定） | 4,949m |
| 5回目 | 1,050～5,099m | 6,000～6,049m |
| 6回目 | 1,050～6,099m | 7,000～7,049m |
| 7回目 | 7,979m（固定） | 7,979m |
| 8回目 | 1,050～8,049m | 8,000～8,049m |
| 9回目 | 1,050～9,049m | 9,000～9,049m |
| 10回目 | 1,050～10,049m | 10,000～10,049m |
| 11回目 | 1,050～11,049m | 11,000～11,049m |
| 12回目 | 1,050～12,049m | 12,000～12,049m |
| 13回目 | 1,050～13,049m | 13,000～13,049m |
| 14回目 | 1,050～14,049m | 14,000～14,049m |
| 15回目 | 1,050～15,049m | 15,000～15,049m |
| 16回目 | 1,050～16,049m | 16,000～16,049m |
| 17回目 | 1,050～17,049m | 17,000～17,049m |
| 18回目 | 1,050～18,049m | 18,000～18,049m |
| 19回目 | 1,050～19,049m | 19,000～19,049m |
| 20回目 | 1,050～20,049m | 20,000～20,049m |
| 21回目以降 | 1,050～20,099m | 約100万m |

入場時の予定距離と、イベントで出口を延ばせる上限は別に決まります。表の上限位置には、
出口が置かれる50m区画内の幅を含めています。上限までの長さが入場時にそのまま
抽選されるわけではありません。
固定の回は出口を置ける区画も一つに限定されるため、イベントや汽車で予定距離を
延ばしたり縮めたりできません。

**歩いて区画を進むだけでは、予定されている出口の位置は変わりません。** 出口が
遠ざかったり近づいたりするのは、NPCとの会話やスイッチの結果、戦闘イベントの開始時、
または汽車で前進して予定の出口に達するか越えたときです。汽車で後退しても出口は
近づきません。どの変更も、その回の設定上限・下限を超えられません。

NPCとの会話やスイッチの後に表示される「出口が遠くなった」「出口が近くなった」という
メッセージは、出口の予定位置を変更する処理に対応しています。ただし、設定上限や下限に
当たって、実際の出口位置が動かない場合もあります。

えんえんトンネルは50m単位の区画で管理されています。イベントごとの変化量は次のとおりです。

| イベントの結果 | 指定される変化量 | メッセージの要旨 |
| --- | ---: | --- |
| トンネル作業員で「短くすべき」を選ぶ | 500m近くなる | すこし近くなった |
| トンネル作業員で「長くすべき」を選ぶ | 500m遠くなる | すこし遠くなった |
| ほかのNPCによる通常の短縮 | 500m近くなる | すこし近くなった |
| ほかのNPCによる通常の延長 | 500m遠くなる | すこし遠くなった |
| 危険なスイッチの延長1 | 1,500m遠くなる | すこし遠くなった |
| 危険なスイッチの延長2 | 3,000m遠くなる | とんでもなく遠くなった |
| 危険なスイッチの短縮1 | 1,000m近くなる | すこし近くなった |
| 危険なスイッチの短縮2 | 2,000m近くなる | とんでもなく近くなった |
| 「出口がすぐそこ」と表示されるNPCイベント | 現在位置より前へ出ない下限まで近づく | すぐそこにあるような気がした |
| トンネル内の戦闘イベントが始まる | 50m遠くなる | 距離変化のメッセージなし |

同じ「すこし遠くなった」という表示でも、NPCでは500m、スイッチでは1,500mです。
「すこし近くなった」も、NPCでは500m、スイッチでは1,000mなので、メッセージだけから
変化量を一意に判断することはできません。

表の距離は、補正がかからない場合の変化量です。出口を近づける処理では、出口を現在位置より
後ろへ置かないように補正されるため、出口が近い状態では表に示した距離をすべて短縮できない
場合があります。遠ざける処理も、トンネルの設定上限を超える分は反映されません。「すぐそこ」
のイベントも100万mを近づける処理ではなく、大きな短縮値を指定して下限補正を働かせています。

## 内部処理

### 開始時の予定長さ

`code.bin`の`sub_494FD0`（`0x4950F4`～`0x49511C`）は、内部カウンター`N`を
読み、最初の出口候補となる区画番号を抽選します。抽選に使う`N`は最大19に制限されます。

```text
候補区画 = 20 + 0～(20 × min(N, 19))の整数乱数
```

続いて`sub_498104`（`0x498124`～`0x498274`）が、区画内の位置として0～49mを抽選し、
`data/res/enen_tunnel/enen_tunnel_event.cfg.bin`の`ENEN_TUNNEL_LENGTH_PARAM`から
`N`に一致する設定を適用します。固定値の設定では、区画番号と区画内の位置を指定距離へ
置き換え、区画の下限と上限も同じ値にします。範囲指定の設定では、候補区画を
下限・上限に収めます。

```text
範囲指定の場合:
予定区画 = clamp(候補区画, 下限 - 1, 上限 - 1)
予定長さ = (予定区画 + 1) × 50m + 区画内の位置（0～49m）
```

| 内部値`N` | 設定項目 / ファイル内オフセット | 設定内容 | 開始時の予定長さ |
| ---: | --- | --- | ---: |
| 0 | 406 / `0x18B8` | 固定794m | 794m |
| 1 | 407 / `0x18D0` | 区画範囲20～40 | 1,050～2,049m |
| 2 | 408 / `0x18E8` | 区画範囲20～60 | 1,050～3,049m |
| 3 | 409 / `0x1900` | 固定4,949m | 4,949m |
| 4 | 410 / `0x1918` | 区画範囲20～120 | 1,050～5,099m |
| 5 | 411 / `0x1930` | 区画範囲20～140 | 1,050～6,099m |
| 6 | 412 / `0x1948` | 固定7,979m | 7,979m |
| 7～19 | 413～425 / `0x1960`～`0x1A80` | 下限2、上限は160から400へ20ずつ増加 | 1,050～`(N + 1) × 1,000 + 49`m |
| 20以上 | 426 / `0x1A98` | 区画範囲2～20,000 | 1,050～20,099m |

設定の区画範囲は、開始時の抽選範囲とは別です。`N`が20以上では設定上限が
20,000区画になりますが、開始時の候補区画は20～400のままです。それより遠い区画へは、
イベントなどによる延長で出口を動かせます。また、候補区画を上限へ収める回では、
上限の区画に複数の抽選値が集まるため、表の距離範囲内で各区画が同確率になるわけでは
ありません。

### 予定長さが変わる時点

開始時の抽選と設定の適用は、初期化済みフラグ`+0x187`が立つ前に一度行われます
（`sub_498104`の`0x498124`、`0x498474`）。歩いて区画を進む処理
`sub_497114`は次のイベントを生成しますが、予定区画`+0x17C`を抽選し直しません。
`N`は保存フラグ`0x8920FFE7`から読みます（`sub_128DA4`、`0x4950F4`）。出口側の
`data/res/map/t131d32`～`t131d35`の各`.pck`内では、`RunCmd_Map1`または
`RunCmd_Map3`がこのフラグを1増やします。節目の値へ設定するコマンドもあります。
更新後の値を使うのは、次に予定長さを初期化するときです。

予定区画が変わるのは、NPC・スイッチの選択を受けた距離変更コマンド1000の実行時、
戦闘イベントの開始時、および汽車の移動先が現在の予定区画に達するか越えたときです。
汽車で後退する場合と、歩いて戻る場合には予定区画を短くしません。

### 現在距離と出口位置

距離関係の処理は、`code.bin`の`0x495564`にあるコマンド分岐へ集約されています。

| コマンド | 役割 | 主な処理位置 |
| ---: | --- | ---: |
| 1000 | 出口の予定区画を増減する | `0x4955B8`～`0x49561C` |
| 1005 | 現在までに進んだ距離を返す | `0x495770`～`0x4957F8` |

トンネル管理オブジェクトでは、現在区画を`+0x178`、出口の予定区画を`+0x17C`に別々に
保持しています。距離変更コマンドは、受け取った符号付き整数を出口の予定区画に加算します。
現在区画や、画面に表示する現在距離へは加算しません。

概念的には次の処理です。

```text
出口の予定区画 = 出口の予定区画 + 変化量
出口の予定区画 = 現在区画および設定された下限・上限の範囲内へ補正
```

通常は、出口を現在区画より前へ戻せません。出口の出現処理がすでに始まっている場合には、
現在区画の1つ前が下限になり、その状態から正の変化量を指定しても無視されます。

### 1区画が50mになる理由

区画の通過判定では、隣の区画までの長さとして内部座標の`500.0`を使用しています
（`0x497F6C`～`0x497F88`）。現在距離を返すコマンドも、区画数へ`500.0`を掛けた値を
使用します。

一方、距離表示スクリプトはその戻り値を10で割ってメートル表示にします。したがって、
出口位置の1区画分は`500 ÷ 10 = 50m`です。

画面の距離表示は、現在距離が変わると新しい値へ最大90フレームかけて追従します。この表示用の
補間も出口の予定区画とは独立しており、出口変更イベントの効果を示すカウンターではありません。

### NPCイベントの変化量

マップイベントは`EnenTunnelLengthAdd`を呼び、引数をコマンド1000へそのまま渡します。
トンネル作業員の選択肢は次の処理に対応します。

| 選択肢 | マップコマンド | トリガー項目 / ファイル内オフセット | 引数 | メートル換算 | 表示 |
| --- | --- | --- | ---: | ---: | --- |
| 短くすべき | `RunCmd_Map129` | 129 / `0x121C` | -10 | -500m | `mes_short` |
| 長くすべき | `RunCmd_Map130` | 130 / `0x1240` | +10 | +500m | `mes_long` |

ほかのNPCイベントでも、通常の延長は`+10`、通常の短縮は`-10`です。内部イベント識別子との
対応は次のとおりです。

| 内部イベント識別子 | 距離変更 |
| --- | --- |
| `npc_101` | -10、+10 |
| `npc_104` | +10 |
| `npc_107` | +10、-20000 |
| `npc_114_01` | -10、+10 |
| `brain_03` | -10、+10 |
| `brain_04` | +10 |
| `brain_05` | -10、+10 |
| `brain_09` | +10 |

`npc_107`の`-20000`は`RunCmd_Map150`で指定され、`mes_end`を表示します。減算後の
出口区画が現在区画より前になるため、下限補正によって「すぐそこ」の位置になります。

### スイッチイベントの変化量

「危険！ スイッチ押すべからず！」と書かれたスイッチには、4種類の距離変更処理があります。

| マップコマンド | トリガー項目 / ファイル内オフセット | 引数 | メートル換算 | 表示 |
| --- | --- | ---: | ---: | --- |
| `RunCmd_Map234` | 234 / `0x20E0` | +30 | +1,500m | `mes_long` |
| `RunCmd_Map235` | 235 / `0x2104` | +60 | +3,000m | `mes_longest` |
| `RunCmd_Map236` | 236 / `0x2128` | -20 | -1,000m | `mes_short` |
| `RunCmd_Map237` | 237 / `0x214C` | -40 | -2,000m | `mes_shortest` |

これとは別に、`RunCmd_Map238`～`RunCmd_Map241`は「このスイッチはもう動かない」と表示する
だけで、距離変更コマンドを呼びません。

### 戦闘イベントの変化量

`RunCmd_Map3`～`RunCmd_Map124`の戦闘イベントは、戦闘を起動する直前に
`EnenTunnelLengthAdd(1)`を呼びます。勝敗を判定した後ではなく、戦闘イベントを開始した
時点で出口が1区画、つまり50m遠くなります。
