# 鬼ガシャの報酬と鬼玉数の関係

## 概要

鬼時間の脱出後や、妖怪ウォッチバスターズ、真・妖怪ウォッチバスターズのクリア後に
回せる鬼ガシャは、鬼玉数に応じてテーブル0～4から1つを選び、その中から景品を引きます。

テーブル0は、1～4のどれにも入らなかった場合に選ばれます。

### 鬼時間

常に共通テーブルを使用します。
鬼玉数が増えると、上位テーブルの抽選枠が一定量ずつ増えます。

| 鬼玉数 | テーブル0 | テーブル1 | テーブル2 | テーブル3 | テーブル4 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 5 | 約73.4% | 15% | 約6.3% | 4% | 約1.3% |
| 30 | 15.5% | 40% | 23% | 14% | 7.5% |
| 50 | 0% | 約29.2% | 約36.3% | 22% | 12.5% |
| 100 | 0% | 0% | 33% | 42% | 25% |

### 妖怪ウォッチバスターズ

どの大作戦でもテーブルを選ぶ確率は共通ですが、大作戦ごとに各テーブルの中身は変わります。
鬼玉数が増えると、上位テーブルの抽選枠がテーブルごとの一定倍率で増えます。

| 鬼玉数 | テーブル0 | テーブル1 | テーブル2 | テーブル3 | テーブル4 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 5 | 約86.6% | 約7.1% | 約3.7% | 約2.0% | 約0.6% |
| 50 | 約76.7% | 約13.2% | 約6.3% | 約2.9% | 約0.8% |
| 100 | 約56.4% | 約26.5% | 約11.5% | 約4.4% | 約1.2% |
| 200 | 0% | 約49.6% | 約38.0% | 約9.7% | 約2.7% |

### 真・妖怪ウォッチバスターズ

鬼玉数が増えると上位テーブルの抽選枠が増え、その増加量はステージによって異なります。
鬼玉数が100個のとき、ステージごとの確率は次のとおりです。

| ステージ | テーブル0 | テーブル1 | テーブル2 | テーブル3 | テーブル4 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 赤鬼、のぼせトンマン、ミツマタノヅチ、つられたろう丸 | 0% | 0% | 33% | 42% | 25% |
| 青鬼、イカカモネ議長、鬼食い | 0% | 約3.3% | 53% | 27% | 約16.7% |
| 黒鬼、トキヲ・ウバウネ、どんどろ、レッドＪ、マイティードッグ | 0% | 約26.3% | 43% | 約20.2% | 約10.5% |
| トリプルボスラッシュ、日ノ神 | 0% | 約30.2% | 43% | 約20.2% | 約6.7% |

同じテーブル番号でも、景品の中身と重みは遊び方・大作戦・ステージによって異なります。
表の確率はテーブルを選ぶ確率であり、特定の景品の入手確率ではありません。

## 内部処理

### 鬼玉数の集計

`sub_645590`（`0x645590`）は、最大4人分の鬼玉のうち、各参加者の有効フラグが
立っている分を合計します。
参照する鬼玉数は構造体の `+0x20`、`+0x48`、`+0x70`、`+0x98` です。状態フラグ
`+0xB6` が0なら、合計を半分にして整数へ変換します。以下では、この処理で得た鬼玉数を
`N` とします。

`sub_4082BC` は `0x4084C4` で1～10,000の乱数を0.01倍し、0.01～100.00の値を
作ります。テーブル4、3、2、1を順に判定し、どこにも入らなかった場合はテーブル0を
選びます。各枠の値は、前の枠で残った確率の範囲内でだけ使われます。例えばテーブル4の
枠が25、テーブル3の枠が42、テーブル2の枠が約69.67なら、実際の確率はそれぞれ25%、
42%、33%で、テーブル1と0には残りません。

### 鬼時間

鬼時間では `CPSL_ORGE_CALC_INFO` の `shin_calc_typa_1` を使い、次の値を
テーブル4から順に判定します。

| テーブル | 抽選枠の値 |
| ---: | ---: |
| 4 | `N / 4` |
| 3 | `N / 2.5 + 2` |
| 2 | `N / 1.5 + 3` |
| 1 | `N + 10` |
| 0 | 先の4枠に入らなかった分 |

テーブル名は `orge_prize_off_0` ～ `orge_prize_off_4` です。テーブルの判定は
`0x4087DC`～`0x40890C`、テーブル名の生成は `0x40890C` にあります。

### 妖怪ウォッチバスターズ

通常のバスターズでは、鬼玉数が30個のときに下表の基準値となります。鬼玉数が
1個変わるたびに、テーブルに応じた増加率を掛けます。テーブル0は残りの確率です。

| テーブル | 抽選枠の値 |
| ---: | ---: |
| 4 | `0.7 × 1.008^(N - 30)` |
| 3 | `2.5 × 1.008^(N - 30)` |
| 2 | `5 × 1.012^(N - 30)` |
| 1 | `10 × 1.014^(N - 30)` |
| 0 | 先の4枠に入らなかった分 |

計算は `0x408754`～`0x4087B8` にあり、べき乗は `sub_1F8360` を使います。
選んだ大作戦の番号とテーブル番号から、`orge_prize_on_0_0` ～ `orge_prize_on_3_4` の
テーブル名を作ります。大作戦によってテーブルの中身は変わりますが、選択の式は共通です。

### 真・妖怪ウォッチバスターズ

真バスターズではステージごとに計算区分が決まります。同じ区分のステージは同じ式で
テーブルを選びますが、テーブルの中身はステージごとに別です。

| 計算区分 | ステージ | テーブル4の枠 | テーブル3の枠 | テーブル2の枠 | テーブル1の枠 |
| ---: | --- | ---: | ---: | ---: | ---: |
| 0 | トリプルボスラッシュ | `N / 15` | `N / 5.5 + 2` | `N / 2.5 + 3` | `N + 10` |
| 1 | 赤鬼、のぼせトンマン、ミツマタノヅチ、つられたろう丸 | `N / 4` | `N / 2.5 + 2` | `N / 1.5 + 3` | `N + 10` |
| 2 | 青鬼、イカカモネ議長、鬼食い | `N / 6` | `N / 4 + 2` | `N / 2 + 3` | `N + 10` |
| 3 | 黒鬼、トキヲ・ウバウネ、どんどろ、レッドＪ、マイティードッグ | `N / 9.5` | `N / 5.5 + 2` | `N / 2.5 + 3` | `N + 10` |
| 4 | 日ノ神 | `N / 15` | `N / 5.5 + 2` | `N / 2.5 + 3` | `N + 10` |

これらの値は `data/res/capsule/capsule_config_0.03.cfg.bin` の
`CPSL_ORGE_CALC_INFO` と `CPSL_ORGE_CALC_INFO_DATA` にあります。計算区分0～4の
先頭項目はそれぞれ `0x19198`、`0x191F8`、`0x19258`、`0x192B8`、`0x19318` です。
ステージと計算区分は `data/res/orge/orge_time_stage.cfg.bin` の `ORGE_STAGE`、
表示名は `data/res/text/menu/orgetime_true_matching_text_ja.cfg.bin` に対応します。

`sub_4082BC` の `0x408580` はステージの計算区分から `shin_calc_typa_%d` を
作り、`0x4085D8`～`0x4086AC` でテーブルを選びます。ステージ番号とテーブル番号から
作るテーブル名は `orge_prize_on_00_0` ～ `orge_prize_on_13_4` です（`0x408728`）。

### テーブル内の景品抽選

すべてのテーブルは `data/res/capsule/capsule_config_0.03.cfg.bin` の
`CAPSULE_RATE_INFO` と `CAPSULE_RATE_INFO_DATA` にあります。テーブルが決まった後、
景品候補の条件を確認し、対象の重みを合計してから抽選します。候補の確認と重み合計は
`0x408958`～`0x408C4C`、最終抽選は `0x40912C`～`0x409188` にあります。
そのため、上の各テーブルの確率は、そこにある特定の景品の入手確率とは異なります。
