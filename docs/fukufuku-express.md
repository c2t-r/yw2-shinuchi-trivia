# ふくふく超特急の出現率と条件

## 概要

ふくふく超特急は、ふくふく超特急パスを持っていると、ゲラゲラ奈落リゾートの次の3駅に
出現することがあります。

- ごくらく温泉
- ゲラゲランド
- きもだ飯

パスを持って駅マップへ徒歩で入り直したとき、最初に表示される行先が
「満福おたふく」になる確率は **約1%** です。駅から隣接マップへ出て戻るたびに、
次の二段階の抽選がやり直されます。

1. 駅マップに入る際、**10%** の確率でふくふく超特急の出現が許可されます。
2. 許可されている状態で列車を選ぶ際、**10%** の確率で通常列車がふくふく超特急へ
   差し替わります。

二段階を両方通る確率が、**約1%（10% × 10%）** です。

最初の許可抽選に外れている間は、同じ駅マップで次の列車を待ち続けても出現しません。
許可抽選は駅マップへの入場時に行われるため、列車が選び直されるたびに出現許可まで
抽選し直す仕組みではありません。

同じ駅にとどまってふくふく超特急を見送った場合、直後の1本はふくふく超特急にはなりません。
存在しませんが、パスを持っていない場合も候補の条件を満たさないため、出現率は0%です。

## 内部処理

### 駅マップへの入場時の出現許可

3駅のスクリプトは `seq/map/prog_map_t001s01.xq`、`prog_map_t001s02.xq`、
`prog_map_t001s03.xq` です。いずれも `MapSeqEnter` から
`t100_TrainAnmBGBuild` を呼び、列車を初期化する前に出現許可を抽選します。
抽選に関わる部分は次の形です。

```text
MapSeqEnter():
    t100_TrainAnmBGBuild()

t100_TrainAnmBGBuild():
    permitted = random(100) < 10
    SetTempBitFlag(0x33CEE5A0, permitted)  // sub14003
    sub15223(crc32(sub13203()))          // 列車の初期化
```

この一時フラグには10%の許可抽選の結果が入ります。外れた場合は0が設定され、
後述の列車条件を満たさなくなります。

`sub15223` はネイティブ関数 `0x4EE040` を経由して `sub_4A7564` を呼びます。
リゾート3駅は駅データ `+0x16` が3なので、通常の初期選択では `0x4A77AC` から
`sub_647548` を呼び、通常列車の選択と特別列車への差替え抽選が行われます。

### 徒歩で駅へ入り直したときの再抽選

駅と隣接マップの出入口は、`t001s01 ↔ t001d01`、`t001s02 ↔ t001d02`、
`t001s03 ↔ t001d03` のマップ移動として定義されています。退出処理では
`0x5AAE20` で `MapSeqExit` を呼んだ後、`0x5AB200` から `sub_4A91B0` を呼び、
列車の状態・駅データへのポインタ・現在の列車へのポインタを0に戻します。

到着済みの列車を保存する一時値 `0x99DCDE6D` も、通常の徒歩移動で駅から隣接マップへ出る際に
`sub_5A0DC0` の `0x5A0F74` で0へ戻ります。判定に使う `MAP_INFO` のフィールド6は、
駅3マップでは `0x40`、隣接3マップでは `0` です。読み込み側の `sub_3DC738` は
この値を構造体 `+0x0C` に保存し、移動先でビット6が外れると列車の保存状態を解除します。
この解除経路は、一時フラグ `0x74E22472` と乗車中フラグ `0xB5F7A5F1` が0で、
列車リソースのフラグ `0xF1E7285C` が1の場合に実行されます。

そのため、駅へ戻った際は前の列車を引き継がず、`MapSeqEnter` の許可抽選と
`sub_4A7564` の初期選択が再実行されます。これに対し、列車から降りて駅へ到着した
直後は、一時フラグ `0xD2419757` により乗ってきた列車を引き継ぎます。
この降車時の表示は、徒歩で入り直した際の新規抽選とは別の経路です。

### 10%の差替え抽選

リゾート3駅の通常列車候補の選択は `sub_647548`、ふくふく超特急への差替えは
`sub_647810` が担当します。差替え側の10%判定は、駅マップへの入場時の許可抽選とは
別の乱数呼出しです。

| 役割 | 仮想アドレス | `code.bin`オフセット |
| --- | ---: | ---: |
| リゾート3駅の通常列車候補の選択 | `0x647548` | `0x547548` |
| 特別列車への差替え | `0x647810` | `0x547810` |
| `random(100)` の呼出し | `0x647864` | `0x547864` |
| 乱数と10の比較 | `0x647870` | `0x547870` |
| 乱数関数 | `0x11F5F8` | `0x01F5F8` |
| 列車条件の評価 | `0x63E660` | `0x53E660` |

差替え処理は次の形です。

```text
if currentTrain == null or currentTrain.type != 3:
    if random(100) < 10:
        for train in station.trainList:
            if train.type == 3 and train.variant == 0 and condition(train):
                return train.index

return normalTrain.index
```

`sub_11F5F8(100)` は32ビットの乱数を100で割った余りを返します。戻り値が0〜9なら
差替え候補を探し、10〜99なら通常列車を維持するため、判定は10%です。

駅マップにとどまって次の列車を選ぶ時点では、`currentTrain` に出発した列車のデータが残っています。
`sub_4A8450` は `0x4A906C` で次の列車を選び、その後の `0x4A9000` で
列車データへのポインタを更新します。差替え判定時に残っている列車の `+0x06` が
特別列車種別3なら、10%判定を行わず通常列車候補を返すため、ふくふく超特急の
直後にもう一度ふくふく超特急が選ばれることはありません。

リゾート3駅では、次の列車を選ぶ `sub_4A8450` も `sub_647548` を通りますが、出現許可フラグの
10%抽選は行いません。したがって、許可フラグが0なら差替え抽選に当たっても出現せず、
許可フラグが1なら、現在の列車が種別3ではない選択時に10%の差替えが可能になります。

### 列車データ

列車の設定は `data/res/train/train_config_0.03c.cfg.bin` にあります。満福おたふく行きの
ふくふく超特急は `TRAIN_DATA` index 69、ファイルオフセット `0xDEC` です。

| フィールド | 値 | 内容 |
| ---: | ---: | --- |
| 0 | `0xE8ED5E40` | 列車ID |
| 1 | `0` | variant |
| 2 | `4` | 列車系統値 |
| 3 | `3` | 特別列車種別 |
| 4 | `0xA21D4487` | 行先「満福おたふく」 |
| 5 | Base64文字列 | 出現条件式 |

満福おたふくから戻る列車は index 70、オフセット `0xE20`、列車ID `0x6F10330C` です。

リゾート3駅では、それぞれ19件の `TRAIN_STATION_TRAIN` が登録され、最後の行が
満福おたふく行きの列車ID `0xE8ED5E40` を参照します。

| 駅 | `TRAIN_STATION` | 列車行 | 特別列車行 |
| --- | ---: | ---: | ---: |
| ごくらく温泉 | index 211 / `0x1B10` | index 213〜231 | index 231 |
| ゲラゲランド | index 233 / `0x1C60` | index 235〜253 | index 253 |
| きもだ飯 | index 255 / `0x1DB0` | index 257〜275 | index 275 |

### 出現条件

往路列車の条件式を復号すると、次の2条件をANDで評価しています。

```text
GetTempBitFlag(0x33CEE5A0) == 1
AND
IsHaveItem(0x151ADC68) == 1
```

一時ビットフラグ `0x33CEE5A0` は、`flag_config_0.01.cfg.bin` の `FLAG_INFO`
index 3839、ファイルオフセット `0xEFE8`、一時ビットフラグ番号142です。
上記の `t100_TrainAnmBGBuild` が、このIDへ許可抽選の結果を書き込みます。

アイテムID `0x151ADC68` は、`item_config_0.04b.cfg.bin` の `ITEM_IMPORTANT`
index 834、オフセット `0x14848` にあります。ここから参照される表示名ID
`0x1D7199D6` は、`item_text_ja.cfg.bin` の `NOUN_INFO` index 1437、オフセット
`0xF6DC` で「ふくふく超特急パス」に対応します。

行先ID `0xA21D4487` は、`system_text_ja.cfg.bin` のテキストindex 383で
「満福おたふく」に対応します。
