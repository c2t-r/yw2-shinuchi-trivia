# ふくふく超特急の出現率と条件

## 概要

ゲラゲラ奈落リゾートの次の3駅では、通常列車が選ばれた後に、ふくふく超特急へ
差し替える抽選が行われます。

- ごくらく温泉
- ゲラゲランド
- きもだ飯

ふくふく超特急パスを持ち、駅の列車待ち処理が有効な状態なら、列車を選び直す1回ごとの
出現率は **10%** です。駅のデータには通常列車と特別列車を合わせて19件ありますが、
19件から1件を等確率で選ぶ処理ではないため、確率は `1 / 19` ではありません。

パスを持っていない場合、ふくふく超特急は候補の条件を満たさないため、出現率は0%です。
データ上でプレイヤーが恒久的に満たす必要がある条件は、ふくふく超特急パスの所持です。

行先の正式表記は「満福おたふく」です。

## 内部処理

### 10%の差替え抽選

通常列車の選択は `sub_6476DC`、ふくふく超特急への差替えは `sub_647810` が担当します。

| 役割 | 仮想アドレス | `code.bin`オフセット |
| --- | ---: | ---: |
| 通常列車候補の選択 | `0x6476DC` | `0x5476DC` |
| 特別列車への差替え | `0x647810` | `0x547810` |
| `random(100)` の呼出し | `0x647864` | `0x547864` |
| 乱数と10の比較 | `0x647870` | `0x547870` |
| 乱数関数 | `0x11F5F8` | `0x01F5F8` |
| 列車条件の評価 | `0x63E660` | `0x53E660` |

差替え処理は次の形です。

```text
if currentTrain == null or currentTrain.type != 3:
    if random(100) < 10:
        for train in station.trainList:
            if train.type == 3 and train.variant == 0 and condition(train):
                return train.index

return normalTrain.index
```

`sub_11F5F8(100)` は32ビットの乱数を100で割った余りを返します。戻り値が0〜9なら
差替え候補を探し、10〜99なら通常列車を維持するため、判定は10%です。

現在の列車データ `+0x06` がすでに特別列車種別3なら、再度の10%判定は行いません。
これは同じ到着状態で特別列車を重ねて差し替えないための分岐です。

### 列車データ

列車の設定は `data/res/train/train_config_0.03c.cfg.bin` にあります。満福おたふく行きの
ふくふく超特急は `TRAIN_DATA` index 69、ファイルオフセット `0xDEC` です。

| フィールド | 値 | 内容 |
| ---: | ---: | --- |
| 0 | `0xE8ED5E40` | 列車ID |
| 1 | `0` | variant |
| 2 | `4` | 列車系統値 |
| 3 | `3` | 特別列車種別 |
| 4 | `0xA21D4487` | 行先「満福おたふく」 |
| 5 | Base64文字列 | 出現条件式 |

満福おたふくから戻る列車は index 70、オフセット `0xE20`、列車ID `0x6F10330C` です。

リゾート3駅では、それぞれ19件の `TRAIN_STATION_TRAIN` が登録され、最後の行が
満福おたふく行きの列車ID `0xE8ED5E40` を参照します。

| 駅 | `TRAIN_STATION` | 列車行 | 特別列車行 |
| --- | ---: | ---: | ---: |
| ごくらく温泉 | index 211 / `0x1B10` | index 213〜231 | index 231 |
| ゲラゲランド | index 233 / `0x1C60` | index 235〜253 | index 253 |
| きもだ飯 | index 255 / `0x1DB0` | index 257〜275 | index 275 |

### 出現条件

往路列車の条件式を復号すると、次の2条件をANDで評価しています。

```text
GetTempBitFlag(0x33CEE5A0) == 1
AND
IsHaveItem(0x151ADC68) == 1
```

一時ビットフラグ `0x33CEE5A0` は、`flag_config_0.01.cfg.bin` の `FLAG_INFO`
index 3839、ファイルオフセット `0xEFE8`、一時ビットフラグ番号142です。同じIDは
3駅の列車待ち処理にも含まれます。

アイテムID `0x151ADC68` は、`item_config_0.04b.cfg.bin` の `ITEM_IMPORTANT`
index 834、オフセット `0x14848` にあります。ここから参照される表示名ID
`0x1D7199D6` は、`item_text_ja.cfg.bin` の `NOUN_INFO` index 1437、オフセット
`0xF6DC` で「ふくふく超特急パス」に対応します。

行先ID `0xA21D4487` は、`system_text_ja.cfg.bin` のテキストindex 383で
「満福おたふく」に対応します。
